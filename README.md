# Local Experts

## Project Description

Local Experts is a web application that connects local businesses and service providers with customers.

## Technologies Used

- HTML
- CSS
- JavaScript
- Java 17
- Spring Boot
- MongoDB
- Spring Security
- JWT Authentication
- Apache Maven

## Features

- User Registration and Login
- Business Registration and Profile Management
- Category and Location-Based Search
- Service Booking and Order Management
- Ratings and Reviews
- Email OTP Verification
- Admin Dashboard
- LEXI Chatbot

## How to Run

1. Open the project in VS Code or IntelliJ IDEA.
2. Configure MongoDB.
3. Run the application using `mvn spring-boot:run`.
4. Open `http://localhost:8080` in your browser.
